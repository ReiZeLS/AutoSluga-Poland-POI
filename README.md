# AutoSluga Poland POI

National catalogue builder for **real automotive places in Poland**, based on [OpenStreetMap](https://www.openstreetmap.org/copyright) / [Geofabrik Poland](https://download.geofabrik.de/europe/poland.html).

Outputs OSM-source traceable, **unverified** business leads. No invented addresses, contact details, reviews, NIP or REGON. Review before publishing any WordPress listing.

See `README_RU.md` and the `Build Poland automotive POI catalogue` GitHub Actions workflow for instructions.
